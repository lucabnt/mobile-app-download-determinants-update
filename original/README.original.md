# Determinants of Download on Mobile App Stores - An Empirical Analysis

**Author:** Luca Bontempi  
**Date:** 14/02/2023  
**Institution:** Master's Thesis, Chair of Marketing, Eberhard Karl University of Tübingen and University of Pavia  

The complete thesis, along with further details about the project, is published and freely available here:  
[lucabontempi.com/blog/determinants_of_download_on_mobile_app_stores/](https://lucabontempi.com/blog/determinants_of_download_on_mobile_app_stores/)

## Abstract

After providing a description of the mobile ecosystem, its participants, and its dynamics, this research aims to determine which characteristic among developer reputation, popularity, and brand—reflected in specific elements on app store product pages—is the most effective in predicting a user's choice to download a mobile application over another.

The experimental results show that:
* Developer brand is generally the most influential factor.
* However, when the opportunity to compare applications is introduced into the model, the brand loses some of its effectiveness, and reputation becomes more relevant.
* The popularity of the application among other users, in a context of low network effects, seems surprisingly ineffective in influencing user choices across all models.
* In addition, user involvement in the application download process reinforces the effect of reputation, whereas when the user is more involved in the specific application category and thus perceives higher risk, applications developed by established brands are more likely to be chosen.
* Finally, it was not possible to identify any significant two-way interaction between reputation, popularity, and developer brand.

## Repository Structure

This repository contains the code, data, source files, and the final research document:

* **`Data and Code/`**: Includes all datasets and the `.r` file (`Determinants of Download on Mobile App Stores - An Empirical Analysis.r`) necessary to replicate the results obtained in this research. The datasets include, among others, the data for ANOVA (`M ANOVA_RM.csv`) and the data for Models 1, 2, and 3 (`M1_rep.csv`, `M2_pop.csv`, etc.).
* **`Figure/`**: Contains images, charts generated via the R script, and diagrams used for writing the thesis (e.g., `M plots.csv`, `Figure 1.png`, etc.).
* **`Final Thesis PDFs/`**: PDF files ready for printing and consultation, formatted in various versions (Pavia, Tuebingen, *onesided*, *twosided*).
* **LaTeX Source Files**: In the main directory, all `.tex` files (Chapters, Appendices, Abstract, Title Page, Lists) and the bibliography (`.bib`) necessary to compile the manuscript are present.
